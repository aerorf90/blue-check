RynWeb PC Check

Application de vérification demandée par le staff du serveur. Pour Windows 10 / 11.

Télécharger pour Windows
  1. Téléchargez et lancez l'application (clic droit → Exécuter en tant qu'administrateur).
  2. Lisez et acceptez ce qui sera analysé.
  3. Entrez le code donné par le staff.
  4. Cliquez sur « Envoyer au staff ».

Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
