RynWeb PC Check

Application de vérification

Un membre du staff d'un serveur vous a demandé de lancer cette vérification de votre PC.

Télécharger pour Windows
Windows 10 et 11Moins de 1 MoDroits administrateur requis
  1. Lancez le fichier téléchargé et acceptez la demande d'autorisation de Windows.
  2. Lisez ce qui sera analysé, cochez l'acceptation et saisissez le code reçu.
  3. Patientez une minute. Vous n'avez rien d'autre à faire.
Windows affiche « Windows a protégé votre ordinateur »

Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Ce message apparaît pour les applications récentes qui ne sont pas encore signées.

Que vérifie l'application ?

Des noms de programmes, l'historique de lancement de Windows, des noms et empreintes de fichiers, les sites récemment contactés et les dossiers FiveM. Jamais vos documents, mots de passe, historique de navigation ou captures d'écran. Seul le staff qui a créé le code voit le résultat. Détails dans la politique de confidentialité.
