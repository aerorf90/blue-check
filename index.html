FAQ

Questions fréquentes

Les informations importantes avant de commencer.

Comment les résultats sont-ils associés au joueur ?

Chaque vérification utilise un code unique. Le rapport envoyé par l’application est associé à ce code et apparaît dans le compte qui l’a créé.

Le score signifie-t-il automatiquement que le joueur triche ?

Non. Un score et des détections sont des indicateurs. Le staff doit examiner les détails avant de prendre une décision.

Comment accéder au tableau de bord ?

Connectez-vous avec Discord, puis activez une clé valide si votre compte le demande.
